# Bóveda Digital

Bóveda Digital busca resolver el problema de almacenar y organizar archivos de forma segura por fecha y hora.
Su objetivo es proteger la información y facilitar el acceso a los archivos desde diferentes lugares.

Autor: Matías

El proyecto se desarrollará progresivamente, priorizando la seguridad y la recuperación de archivos.

## Estado del proyecto

Proyecto en fase inicial de organización y documentación.
