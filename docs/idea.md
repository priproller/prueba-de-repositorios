# Idea de la aplicación

## ¿Quién tiene el problema?

Personas y organizaciones que necesitan guardar archivos importantes, organizarlos y acceder a ellos desde diferentes lugares sin perder su información.

## ¿Qué información necesita registrar?

- Nombre del archivo.
- Tipo de archivo.
- Fecha y hora de almacenamiento.
- Ubicación del archivo.
- Propietario.
- Estado de las copias de seguridad.
